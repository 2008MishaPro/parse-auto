# Авито: механизмы для переноса

Выбираем небольшие механизмы, а не целый чужой продукт. Все источники ниже — доноры идей/кода, не доказательство текущего live-доступа. Перед буквальным переносом закрепить commit и подходящую лицензию; при неподтверждённой лицензии реализовать алгоритм самостоятельно.

Срез общей организации 2026-10-11 не добавляет доноров или зависимостей: рабочие пути searches.json/data/state/data/run не зависят от региона. Штатный export --search-id использует уже сохраняемый membership/alias из FileStore; временный региональный скрипт отбора по observedAt перенесён в data/archive/2026-10-11/regional-preflight и больше не нужен для выгрузки. Исторические региональные live-отчёты из разделов ниже находятся в том же архиве, результаты не переписаны. Проверки текущего среза — STATE.

## Конкретный путь Авито

1. Вход — готовый URL автомобильного поиска с выбранными фильтрами. Сохранять его параметры; сортировку «новые сначала» включать только по проверенному mapping.
2. API-вариант: [url_converter.py](https://github.com/Duff89/parser_avito/blob/master/parser/url_converter.py) + [HTTP client](https://github.com/Duff89/parser_avito/blob/master/parser/http/client.py) → конкретный запрос каталога. Его URL/параметры ещё необходимо воспроизвести; не подставлять выдуманный endpoint.
3. HTML-вариант: GET URL → script[type="mime/invalid"][data-mfe-state="true"] → HTML entities → JSON.parse → loaderData.data. Это кандидат по донору; текущую структуру/список объявлений подтвердить живым ответом и fixture. DOM-вариант включается по проверенным селекторам.
4. Extractor отдаёт ID, URL, цену и доступные поля; запрос следующей страницы строится по проверенной пагинации. Проверить, что page 2 не повторяет page 1.
5. Normalizer выдаёт общий DTO. Карточки для дополнительных полей получать отдельно и ограниченно, не все старые объявления каждый быстрый цикл.
6. Ядро сохраняет страницу, сравнивает ID/последнюю цену и планирует следующий цикл. Догон/полная сверка принадлежат ядру, а не бесконечному while внутри адаптера.

## Что не переносить

Уведомление до commit, unknown price=0, дедуп по тексту/цене вместо source+ID, прекращение обхода на знакомом объявлении, молчаливые ошибки, ограничение мониторинга первой страницей и чужую UI/ИИ-обвязку. Ни один выбранный донор сам по себе не доказывает 100% охвата.

## Первый живой срез E1, 2026-10-11

Проверен `Duff89/parser_avito@91a5399f79bf035d3eb919d66ada00545571c2f1`: [URL converter](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser/url_converter.py), [HTTP client](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser/http/client.py), [SSR extraction](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser_cls.py). GitHub metadata: `license=null`; в дереве отсутствуют LICENSE/COPYING/NOTICE. Буквальный перенос не выполнялся; код CarRadar написан самостоятельно по живому ответу.

Converter делает POST на сторонний `https://spfa.pro/api/avito-url/`, передавая `{url}` и получая `api_url`. Live POST завершился timeout 25 секунд; точный JSON endpoint автомобильного каталога не подтверждён. Эти зависимости не перенесены.

В первом срезе работал Node.js native `fetch` GET `https://www.avito.ru/moskva/avtomobili`, без cookies/прокси/браузера. Ответ HTTP 200, около 2.9 MB, literal JSON в `script[type="mime/invalid"][data-mfe-state="true"]`. JSON читается первым; HTML entities декодируются только при неудаче прямого JSON.parse, чтобы не изменить текст внутри строк. Путь записей: `loaderData.data.catalog.items`, автомобиль `type=item`, `categoryId=9`; `type=banner` учитывается отдельно.

Пагинация — готовый `catalog.pager.next`, подтверждённые страницы 1 и 2 имеют различные наборы ID. На последней доступной странице 30 поля next/last отсутствуют; конец подтверждён номером страницы и пределом `1500 / 50`. `mainCount/count` широкого поиска примерно 84 тысячи, `totalElements=1500`: ограничение сайта выводится явно. У Honda S2000 в Москве pager отсутствует; `mainCount=count=itemsOnPageMainSection=3` совпадает с тремя основными объявлениями, а `totalCount=7` включает рекомендации и не используется как количество найденных машин.

`q=Honda S2000&s=104` может вернуть HTTP 200 с SSR redirect на канонический путь — адаптер следует подтверждённому URL с ограничением переходов. SSR mapping `s=104` — «По дате»; сортировка пока не даёт оснований для timestamp watermark. `allowTimeStamp`/`sortTimeStamp` не объявляются датой публикации.

Цена берётся из согласованных `priceDetailed.value` и полной RUB-строки, в копейках. «От», кредит, взнос, аванс и непроверенные суммы дают null. Исходные listing/query URL сохраняются; меняющийся context URL не считается изменением существенных деталей. Три минимальные fixtures сохраняют только нужные поля без профилей/изображений/описаний продавцов.

В первом срезе два выборочных GET карточек получили HTTP 439 «Доступ ограничен: проверка безопасности». Цена/ID были сверены с SSR выдачи; сверка с карточками тогда оставалась незавершённой. Системный curl получил TLS handshake error; тот же каталог через native fetch работал, поэтому браузер/curl_cffi не добавлялись.

## Карточки и штатная проверка страницы, 2026-10-11

Для конкретного запроса карточки дополнительно прочитан тот же закреплённый [HTTP client](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser/http/client.py). Донор использует `https://m.avito.ru/api/1/card/items/{item_id}` с mobile-заголовками, `curl_cffi` и cookie/fingerprint-сессией. Живой запрос этого точного endpoint вернул HTTP 429 «Доступ ограничен: проблема с IP»; путь не выбран. [OwnCookiesProvider](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser/cookies/own_cookies.py) лишь читает/обновляет cookies и ждёт при отказе; [внешний provider](https://github.com/Duff89/parser_avito/blob/91a5399f79bf035d3eb919d66ada00545571c2f1/parser/cookies/external_api.py) передаёт получение/обновление сессии сервису SPFA. Эти зависимости и код не перенесены.

Выбран desktop HTML: публичный JS страницы HTTP 439 описывает штатную проверку `POST /web/3/firewallPow/get` → `SHA-256(id:nonce)` с заданным количеством начальных нулей → `POST /web/3/firewallPow/verify` → повторный GET исходной страницы. CarRadar реализует только этот наблюдавшийся протокол самостоятельно; скрипты страницы не исполняются. Отсутствие лицензии донора по-прежнему исключает буквальное копирование.

Текущий транспорт `AvitoHttpSession` использует native `fetch`, приватные cookies только в RAM, FIFO и минимум 2 секунды между всеми HTTP-запросами, включая проверку/redirect/reload. Cookies промежуточных ответов сохраняются; ручные HTTP-переходы ограничены тремя и тем же origin, verification POST не пересылается. Один общий timeout/AbortSignal включает очередь, ожидание, вычисление и чтение ответа. Распознанная проверка HTTP 439 выполняется один раз: допустимая сложность 1–5, максимум 2 000 000 попыток nonce. Неизвестная проверка, капча, проблема с IP и повторный отказ автоматически не преодолеваются; отказ остаётся явным blocked либо rate_limited при HTTP 429. Cookies/JWT не выводятся и не сохраняются в журнале.

Карточка разбирается независимо от каталога: JSON-строка в `window.__staticRouterHydrationData = JSON.parse(...)` → `loaderData['catalog-or-main-or-item'].buyerItem.item`. В наблюдавшемся `window.__preloadedState__` карточки нет; произвольный поиск вложенных `item` не применяется. `JSON.parse` читает данные без eval. Проверяются ID, URL и автомобильная категория; полная RUB-цена подтверждается согласованными `item.price`, `formattedPrice.value`, `formattedPrice.formatedString` и `currencySign`. Вложенная оценочная цена не используется; неподтверждённая цена, vehicle и publishedAt остаются null. Минимальная `fixtures/avito/live-card.html` хранит лишь необходимые поля без cookies, токенов, профилей и телефонов.

Сверка `data-card-diagnostic/check-report.json`: **2026-10-11 11:43:10–11:43:23 МСК**, каталог HTTP 200 и три карточки HTTP 200; ID, полные цены и названия совпали:

Получение потребовало 7 реальных HTTP-запросов: 1 каталог + 1 первая карточка + 4 запроса второй карточки с проверкой + 1 третья карточка. Это снимает исходный блокер выборочной сверки E1, но не доказывает доступность всех карточек или долгую устойчивость канала. `getDetails` опционален; постоянный мониторинг сам не запрашивает все карточки. ## Характеристики автомобилей, 2026-10-11

Для конкретной задачи характеристик использован уже подтверждённый desktop SSR и тот же native AvitoHttpSession, без нового транспорта, зависимостей или донорского кода. Ограниченная проверка **17:52:58–17:53:06 МСК**: одна страница каталога HTTP 200 и одна карточка HTTP 200; всего **5 native HTTP**, включая один штатный 439/get/verify/reload. Безопасный отчёт — data/reports/vehicle-source.json. В трёх проверенных catalog items и JSON-LD отдельных make/model/year/mileage не обнаружено; это не утверждение об отсутствии полей на всех страницах сайта.

В карточке **8366290005** обнаружен плоский блок `window.__staticRouterHydrationData.loaderData['catalog-or-main-or-item'].buyerItem.ga[1]`: brand=`ВАЗ (LADA)`, model=`2101`, year=`1976`, mileage=`250 000 км`. GA служит аналитике, поэтому индекс не является контрактом: наш parser ищет фактический flat блок, принимает только один согласованный набор полей и указывает найденный индекс в provenance. Различные полные наборы, несогласованность года/пробега со строгим title или марки+модели с его началом запрещают приём GA характеристик. Вложенные произвольные analytics-данные не обходятся. Минимальная fixtures/avito/live-vehicle-card.html сохраняет лишь необходимые публичные поля, без цены/контактов/cookies/JWT/полного HTML страницы. Это самостоятельная реализация по наблюдавшемуся ответу, а не перенос чужого кода.

Названия живого каталога и прежних Honda fixtures подтверждают форму `, YYYY, N км`; в 207 сохранённых региональных titles также наблюдалась `, YYYY, битый, N км`. Самостоятельный строгий parser принимает только эти две формы, целый safe пробег с правильными группами и допустимый год относительно observedAt. Year/mileage каталога имеют provenance title; make/model не угадываются. Неподтверждённые поля остаются null. Read-only preview распознал **1151/1151** накопленных региональных названий; это не независимая проверка карточек и не backfill состояния. Автоматического запроса всех карточек нет. **365/365 полных регрессий и typecheck --noEmit прошли**, билд не выполнялся; короткий источник/fixture тест не закрывает длительную приёмку E2.

Дополнительная проверка **21:12:05–21:12:16 МСК** использовала уже сохранённые ID и настоящий AvitoAdapter.getDetails без нового каталожного обхода: ВАЗ 2114 Samara 8543261595 (2007/200000 км), Daewoo Nexia 8545010922 (2001/300000 км), битая Priora 8378691370 (2009/234000 км). Все три карточки HTTP 200, brand/model/year/mileage подтверждены в flat ga[1]; индекс по-прежнему определяется фактически. Всего **6 native HTTP**, одна штатная проверка 439 у Nexia. ID/title/цены совпали с сохранёнными наблюдениями; SHA-256 snapshot/journal не изменился. Безопасные артефакты — data/reports/card-vehicle-check.json и fixtures/avito/live-vehicle-cards.json. Всего наблюдались четыре карточки с этим источником характеристик, доступ/структура всего сайта не гарантируются. Новых доноров/зависимостей нет. Диагностика и карточные регрессии проверены точечно: **52/52 pass + typecheck --noEmit**, полного прогона в этом срезе не было.

## Файловые снимки E2, 2026-10-11

Файловые snapshot/compaction в срезе E2 реализованы самостоятельно поверх уже проверенных sequence/checksum/fsync, очереди store и writer lock. Выбранные доноры не дают готового протокола сохранения наших membership/knownPrices/page replay/eventId. Новый temp+fsync+rename снимок публикуется прежде замены журнала с anchor; выбор проверен миграцией живого журнала, crash на трёх шагах публикации и конкурентными читателями на Windows. Чужой код/новые зависимости для этого механизма не переносились.

## Постоянные группы E2, 2026-10-11

Постоянные привязки группы source/точный URL реализованы самостоятельно поверх существующих journal/snapshot/fsync, без новых зависимостей и переноса кода донора. Они устраняют повторный baseline при смене первого enabled ID, сохраняя прежние membership/цены/eventId. Совместимость проверена старым журналом/снимком, restart/compact, отказом при конфликтной истории и живой сменой всех ID на копии состояния. Новый транспорт для этой задачи не требуется.

## Состояние источника и история gaps E2, 2026-10-11

Общее состояние источника и история gaps реализованы самостоятельно поверх тех же journal/snapshot/fsync. Донорский HTTP-клиент не хранит наши query/checkpoint/eventId и не решает восстановление общей серии ошибок разных поисков. Запись health внутри FIFO выбрана для сохранения Retry-After до следующего HTTP; query+gaps в одном batch — для сохранения всех уже наблюдаемых оснований до вывода. Проверены чередование ошибок/restart, глобальный stop при ошибке записи, clock rollback, legacy import и живые циклы/рестарт; новых зависимостей и переноса чужого кода нет.

## Supervisor E2, 2026-10-11

Supervisor написан самостоятельно на Node child_process/fs/IPC, без runtime-зависимостей и переноса донорского кода. Он нужен для одного сохранённого CLI-процесса на Windows: ожидает close перед restart, сохраняет раздельные логи/выборочную память и не обходит writer lock/source backoff. Crash/IPC disconnect/stop, ранняя потеря parent, stale lock, bounded restart и отказ до HTTP проверяются настоящими дочерними процессами. Это управление процессом; сортировка/пагинация остаются в Avito adapter, обход/события — в ядре.

## Неполная последняя страница Авито E2, 2026-10-11

Живой q=Honda%20Civic&s=104 дал 165 основных результатов, первые три страницы по 50 и p4 с 15 машинами + banner. На p4 itemsOnPage/itemsOnPageMainSection=15 — это фактический остаток, а totalElements=200 — округлённая ёмкость; деление 165/15 ошибочно требовало 11 страниц. SSR pager.current=4, pages содержит согласованные ссылки 1–4; next/last отсутствуют, DOM не указывает следующую страницу. Metadata без полного HTML/cookies/токенов сохранена в data-pilot-preflight/last-page-metadata.json. Фильтр может включать другие города по правилам географии/доставки сайта.

По этому конкретному ответу добавлено ограниченное самостоятельное правило конца: известная наблюдённая ёмкость 50, source/count/totalCount согласованы и ≤1500, rounded totalElements, точный остаток основных валидных уникальных ID, совпадение request/current/currentHref и проверенные ссылки всех numeric pages, без cap/DOM-next. diagnostics.pageCapacity передаёт ёмкость, itemsOnPage остаётся фактическим числом; ядро использует ёмкость для оценки бюджета без условия по имени источника. Unknown/противоречия, отсутствие pager или неполный numeric pages набор не подтверждают конец этим правилом. Положительные и отрицательные свидетельства проверены 25 регрессиями; новый канал/донор/зависимости не нужны.
